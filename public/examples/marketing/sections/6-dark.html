Event delivery API

Events that arrive. Every time.

Relay delivers your events with retries, signing and a full delivery log, so you can stop writing queue code.

Get an API key Read the docs

Install

$ npm install @relay/node
import { Relay } from '@relay/node'

const relay = new Relay(process.env.RELAY_KEY)

await relay.events.send({
  endpoint: 'ep_orders',
  type: 'order.paid',
  data: { id: 'ord_1042', total: 4900 },
})
import os
from relay import Relay

relay = Relay(os.environ["RELAY_KEY"])

relay.events.send(
    endpoint="ep_orders",
    type="order.paid",
    data={"id": "ord_1042", "total": 4900},
)
